このフォルダには、漢字でんしゃという子ども向け学習アプリのために自動生成した音声ファイルが
入っています。「山」という漢字ひとつぶんの、お試し（パイロット）バッチです。

聞いていただきたいのは **4つのファイルだけ** です。それぞれ `manifest.json` に対応する記録が
あります（ファイル名で対応関係がわかります）。

## 大事な区別：読み方 と ことば

ファイルには2種類あり、**判定の基準がちがいます**。

1. **読み方（citation reading）** — 「サン」「やま」のように、単独の読み方だけを読み上げたもの。
   → **明瞭で、不自然でなければOK** です。アクセントは厳密に見なくてかまいません。

2. **ことば（word surface）** — 「山」「火山」のように、実際の単語として読み上げたもの。
   → **アクセント（高低）が正しいかどうかを厳密にチェックしてください。**
   「なんとなく自然に聞こえる」だけでは判定基準として不十分です。必ず以下のどちらかで
   確認してください：
   - NHK日本語発音アクセント新辞典
   - OJAD（Online Japanese Accent Dictionary, https://www.gavo.t.u-tokyo.ac.jp/ojad/）

   印象だけで「大丈夫そう」と判断しないでください。それがこのチェックで一番防ぎたい間違いです。

## 各ファイルへの記入方法

以下の表に、ファイルごとに記入してください。

| ファイル名 | 種類 | 判定（合格 / 不合格） | 自由記述（気づいたこと・訂正すべきアクセントなど） |
|---|---|---|---|
| san_on.wav | 読み方（サン） | | |
| yama_kun.wav | 読み方（やま） | | |
| yama_1.wav | ことば（山） | | |
| kazan_1.wav | ことば（火山） | | |

**不合格にした場合**は、自由記述欄に具体的な訂正内容（正しいアクセント型、何拍目が高いかなど）
を書いてください。この情報は `manifest.json` の `audio_query` を直接修正して再生成するために
使います — 感想ではなく、直せる形の指摘をお願いします。
